# To-Do List

Lista de tarefas simples feita com HTML, CSS e JavaScript puro (sem frameworks).

## Funcionalidades

- Adicionar tarefa pelo campo de texto ou tecla Enter
- Marcar tarefa como concluída
- Remover uma tarefa
- Botão "limpar" aparece só quando há tarefas na lista

## Como rodar

Abra o arquivo `index.html` no navegador. Não precisa de build nem servidor.

## Estrutura

| Arquivo | Responsabilidade |
|---|---|
| `index.html` | Marcação da página |
| `style.css` | Estilos e animações |
| `index.js` | Lógica da lista |
